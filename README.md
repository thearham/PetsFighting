# Pets Fighting

A 2D local multiplayer fighting game built with Unity where adorable pets battle it out!

## Gameplay

Two players control different pets (Dog vs Bear) and fight in a 2D arena. Each pet has unique attacks, movements, and special abilities.

### Controls

**Player 1 (Dog)**
- `A` / `D` - Move left/right
- `W` - Jump
- `Space` - Attack

**Player 2 (Bear)**
- `←` / `→` - Move left/right
- `↑` - Jump
- `Enter` - Attack

## Features

- **2D Fighting Mechanics** - Smooth movement, jumping, and combat
- **Special Attacks** - Unique fury and spark abilities
- **Health System** - With health drops and damage effects
- **Camera Shake** - Dynamic feedback during battles
- **Animated Sprites** - Custom animations for idle, walk, jump, attack, and hurt states

## Built With

- Unity (2D)
- Universal Render Pipeline (URP)
- TextMesh Pro

## Getting Started

1. Clone the repository
2. Open the project in Unity (2021.3 LTS or later recommended)
3. Open `Assets/Scenes/Level.unity` or `Assets/Scenes/SampleScene.unity`
4. Press Play!

## Project Structure

```
Assets/
├── Animations/     # Character animations and controllers
├── Prefabs/        # Reusable game objects
├── Scenes/         # Game levels
├── Scripts/        # C# game logic
├── Sounds/         # Audio files
└── Settings/       # URP and render settings
```
